# 铜鼓麻将规则（本地标准版）

> 江西宜春铜鼓县本地打法 · 由本地牌友实测校对整理

## 这是什么

铜鼓麻将的完整规则速查。网上流传的"宜春麻将""搭砖铜鼓麻将"资料与本地实际规则不符（部分为 AI 编造内容），不可采信，故整理此文档存档。

## 规则速览

- **牌数**：136 张，无花牌（万/筒/条各 36 + 东南西北 16 + 中发白 12）
- **精（宝）**：万能牌。开局掷骰定庄后，庄家在牌墙尾部按骰子点数数墩翻开**指示牌**，指示牌的**下一张**即宝，每局随机
- **吃牌特色**：峰牌（东南西北）、箭牌（中发白）**任意两张可以吃**上家打出的同组一张牌
- **计分**：`总分 =（平胡 1 分 × 牌型倍率叠乘）+ 杠分`，所有牌型 **8 分封顶**
- **有宝 = 折半**：大七对/小七对无宝 ×4，有宝折半 ×2（宝万能、胡牌更容易）
- **德国**：精只按字面牌用（未当赖子）= 没有宝的胡牌，×2
- **精吊**：剩 1 张精单吊当将，亮精即胡（无需自摸）
- **流局/黄庄**：本局杠分全部不算

## 牌型分表

| 牌型/情形 | 倍率 |
|---|---|
| 平胡（基数） | 1 分 |
| 十三烂 / 德国 / 点炮 / 自摸 / 抢杠 / 杠上开花 / 单吊（精吊） | ×2 |
| 大七对 / 小七对 / 七星十三烂 | ×4（七对有宝折半 ×2） |
| 杠上金调 | ×4（相对基础分） |
| 豪华小七对 | 原小七对基础上翻倍（无宝 ×8 / 有宝 ×4） |

杠分独立加分不叠乘：明杠/补杠 3 分、暗杠 6 分（流局作废）。
